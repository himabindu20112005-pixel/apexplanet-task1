# 3D Figurine Carousel Page

A responsive and interactive 3D Figurine Carousel website built using HTML, CSS, and JavaScript.

## Project Overview

This project showcases a collection of 3D figurines through an attractive carousel interface. Users can browse different figurines using interactive navigation controls and enjoy a visually appealing experience across desktop and mobile devices.

## Features

* Interactive 3D-style carousel
* Responsive design for all screen sizes
* Smooth navigation between figurines
* Modern and attractive user interface
* JavaScript-powered interactions
* Mobile-friendly layout

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

* index.html
* style.css
* script.js
* images/

## How to Run

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Use the carousel controls to explore the figurines.
